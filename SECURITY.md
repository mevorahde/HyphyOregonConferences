# Security policy

## Supported version

Security fixes are currently considered for the `1.0.0-rc.1` release candidate.

## Reporting a vulnerability

Please use the repository's private GitHub security-advisory reporting feature
when it is available. If private reporting is unavailable, contact the project
owner without including exploit details in a public issue.

Include the affected version, operating system, observed behavior, and a
minimal reproduction. Reports will be reviewed as time permits; no response or
resolution timeline is guaranteed.

The release archives are unsigned. Verify the accompanying SHA-256 checksum
before use.
