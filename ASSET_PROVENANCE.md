# Asset provenance

The modern tree-and-bridge icon was generated with OpenAI's built-in
image-generation tooling under the project owner's direction on July 28, 2026.
It was iteratively customized for the Hyphy Oregon Conference Generator.

An external bridge photograph was used only as loose structural inspiration.
No words, lettering, team marks, league branding, or exact logo geometry were
copied.

The superseded legacy icon remains available only through Git history and the
local `legacy-dotnet-framework-4.5.2` baseline tag. The modern icon is
distributed with this project under the project's MIT License.
